# AXI 存储项目：从输入到读回结果

这个项目接收读写请求，经过 AXI、UCIe 和内存模型处理，再返回真实数据和完成时间。
第一次使用，先完成“写入 41，再读回 41”的小实验，再学习波形和内部模块。

## 先分清三个项目

本项目的独立负载放在 `examples/*.json`，当前没有 `user/` 目录。
CoralNPU 和 Vortex 的 `user/` 放计算程序，它们会主动产生 AXI 访存。
两个计算项目直接连接本项目的信号接口，不会先把每笔访存写成输入 JSON 再调用本项目的脚本。

`--input` 后面是事务 JSON 的路径。当前文件入口没有逐周期 CSV/VCD 信号回放功能。
如果已有上游 AXI 信号，按 [接口契约](../INTERFACE.md) 连接 SystemC 端口。

## 阅读时的几个约定

- 命令前会写明所在目录；`results/` 是 AXI 独立入口的结果目录。
- “预期”表示根据输入和源码应得到什么；实际是否通过，要打开自己这次运行的 `summary.json`。
- [输出说明](OUTPUTS.md) 中 2026-09-25 的结果是历史运行记录，保留供比较。
- 本轮文档完善核对当前源码、配置和入口；文档检查与重新执行硬件仿真分开记录。
